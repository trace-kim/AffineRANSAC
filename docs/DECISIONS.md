# Decision Log

The decisions behind `docs/SPEC.md`, one row each, with the reason. The spec, the code comments and the
changelog cite them by number (D123). Find a row with `grep -n '^| D123 ' docs/DECISIONS.md`.

- `docs/SPEC.md` describes what the code does now. This file is the history: it also holds decisions that
  later rows replaced or reverted, so read a row together with the spec section that cites it.
- A new decision takes the next number; its row goes right after the row with the highest number so far.
